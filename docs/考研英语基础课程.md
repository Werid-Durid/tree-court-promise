# 考研英语基础课堂

参考用户指定的 [2027刘晓燕考研英语词汇、语法课程](https://www.bilibili.com/video/BV1f1nW6HEyA/)。公开元数据保存于 `knowledge/build/postgrad/BV1f1nW6HEyA-view.json`。

## 来源边界

公开目录共有41个分P：1个使用说明、40个lesson。11个标题包含scare、previous、advance、desirable、expand、tense、relate、fantasy、cognitive、confirm、appearance，能够确认词汇主题。其余29个仅有编号，正文内容尚未确认，不能把这些编号擅自匹配到语法知识点。

`knowledge/postgrad_series_mapping.json` 对29个内容未确认的分P保留原链接和空映射，标记 `lesson_content_unconfirmed`。没有取得字幕、讲义和完整原词表，因此本次是原创基础课接入，不是整套视频内容转写。语法与长难句依据课程标题作原创主题衔接，来源标记为 `original_prerequisite_supplement`；11个已确认词汇主题的例句和记忆钩子也全部原创。

|板块|课时|

共32课。每课包含语境讲解、易错边界、板书、三步例句拆解、短答迁移练习、机制回顾、章节检测与原创记忆线索。那刻夏授课，风堇提供提示，遐蝶核对限制，白厄用生活类比参与；角色档案不改。

“课程表→考研英语”自由选择板块和课时；“智库→书架→考研英语”提供六册笔记和练习，继续使用原有进度及好感贡献逻辑。不是新增独立考试科目，也没有把CET4、CET6题库混入考研英语。

语法核对参考：[Cambridge stop doing / stop to do](https://dictionary.cambridge.org/grammar/british-grammar/stop-ing-form-or-to-infinitive)、[British Council 分词从句](https://learnenglish.britishcouncil.org/grammar/c1-grammar/participle-clauses)。原创中文解释未将这些参考冒称指定课程原文。

## 数据与复现

- `knowledge/postgrad_rows.py`：原始教学条目。
- `knowledge/publish_postgrad.py`：目录发布脚本，先备份并严格保留其他科目和人物。
- `knowledge/postgrad_lessons.json`：32课完整内容。
- `knowledge/postgrad_series_mapping.json`：41分P、11个词汇主题映射和未确认清单。
- `web/tests/test_postgrad_course.py`：独立答案核对、来源边界、四人台词索引及其他课程保留。
- `web/tests/postgrad-browser.mjs`：独立8779测试档案，检查课程、例句、正误反馈、12题章节检测、智库与移动端。
- `web/tests/postgrad-production.mjs`：正式8765只读验证目录、智库和首课分角色音频。

语音沿用本地角色参考音色引擎，按角色和全文哈希匹配，禁止播放文字不符的旧音频。首课10段已生成，包括开场、教师三阶段、三位搭档、初始提问与两种反馈；正式站点已验证三阶段和三位搭档共6段音频可解析播放。剩余课程进入全课程队列，以 `data/voice/manifest.json` 的实际覆盖为准，队列启动不代表全部生成。

验收记录保存在 `web/.runtime/postgrad-browser/`；后台配音日志在 `data/voice/research/postgrad-first-lesson.log` 和 `postgrad-priority.stdout.log`。不重置正式用户学习进度。

2026-10-25 验收：101项后端、33项前端测试通过；隔离浏览器8项检查通过，词汇章12题检测评分100分；正式8765只读验收通过。正式进度epoch与更新前一致。
