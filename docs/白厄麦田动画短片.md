# 白厄麦田动画邀约

启动项目根目录的「启动树庭网站.bat」，在「同行之人」白厄卡片点击「动画邀约 · 把今天留在风里」。播放中会出现对白和选项，选择后播放对应回应，再返回主片。也可下载带字幕的连续观看版。
