# 自习室 · 专注陪伴模式

当前网页已升级为四人中选一人的 Blender 三渲二视频循环，详见[四人动画与自习室](四人动画与自习室.md)。本文下方的单人 GLB 与镜头采样记录保留为旧版制作记录。

参考《未定事件簿》的「专注（陪伴）模式」（BV1qE421j74V）：角色安静陪坐、一个计时器、环境声与极简界面。本轮把原来的「动态壁纸 + 歌单」整页替换成这个模式。

## 入口

- 独立页：`/wallpaper`（后端路由 `web/backend/app.py` 的 `/wallpaper` → `web/frontend/study-wallpaper.html`）。
- SPA 里的入口文案已改为「☾ 专注陪伴模式 · 自习室 ↗」；SPA 自己的 `#focus` 页仍保留计时与 3D 小窗。

## 功能

| 功能 | 说明 |
|---|---|
| 计时环 | 25 分钟一轮，SVG 圆环按进度填充，中央大字倒计时 |
| 开始 / 暂停 / 结束 | 开始后「暂停片刻」；结束会结算本次分钟数并回到 25:00 |
| 今日统计 | `localStorage` 保存今日分钟数与完成轮数 |
| 陪伴语 | 那刻夏的短句，开始/暂停/结束时切换，专注中每 5 分钟轮换 |
| 环境声 | 程序化低频噪声（无外部音频），可开关 |
| 自动暂停 | 切出页面（`visibilitychange`）时自动暂停 |
| 全屏 | 右上角按钮 |

## 3D 与布局

- 复用 `web/renderer/study-wallpaper.js` 编译出的 `study-wallpaper.bundle.js`：自习室、那刻夏写字循环（`TC_Anaxa_StudyWrite`，已烘焙头发/衣摆物理）、尘埃与台灯呼吸、60 秒近景推拉。
- 界面为**右下角紧凑面板**（约 300px），角色与书桌是主视觉；移动端居中贴底。

## 抬头片段（14–18.5 秒）

`blender/create_study_motion.py` 在写字循环里加了一个「抬头看你 → 停一下 → 低头」的窗口：

- `首` 骨骼从低头 29° 抬到 8°，`上半身` 同时直起一点，`頭` 略微偏向镜头；
- 右手在抬头时**停笔并抬起**，低头后恢复运笔；
- 两端用 ease 包络，回到书写不会有跳变。

实测 `study/anaxa.glb` 的 `首` 旋转：t=14 → 27.9°，t=15 → 9.95°，t=16 → 8.13°，t=18 → 22.5°，t=19 → 29.4°。截图 `web/.runtime/study-wallpaper/lookup.png`（约 15.5 秒，脸抬起看向镜头）。

## 说明

- 计时只在页面可见时推进；关闭页面不补算离线时间。
- 环境声是浏览器内生成的噪声，不依赖外部音频文件。
- 角色的表演是「写字 + 每 24 秒抬头看你一次」；想更频繁可改 `create_study_motion.py` 的窗口时间。
