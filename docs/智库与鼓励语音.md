# 智库与角色鼓励语音

正式入口：`http://127.0.0.1:8765/#library`。同行之人入口保持 `#companions`。

## 智库

- **书架区**直接索引正式课程目录中的有效章节，当前 203 册、2662 个知识点。支持跨科目、板块、关键词查找。
- 每册包含知识点目录、教材讲解、板书、例题推演、记忆线索和对应练习；有教材课程的条目沿用完整教材段落。
- 补充笔记保存在浏览器 `treecourt.web.v1.knowledgeNotes`，刷新后保留，可随当前筛选书架导出 TXT。它是当前设备的本地笔记，不宣称跨设备同步。
- 练习复用 `attempt` / `course_attempt` 与原有章节测试；真实回答进入原学习档案，沿用原先每日练习贡献上限，不因翻阅笔记增加好感。
- **考试区**入口 `#library-exams`，汇总本地四、六级真题，支持全部/级别/年份筛选、倒计时、答卷保存、继续作答、交卷锁定及交卷后查阅解析。
- 默认四级 125 分钟、六级 130 分钟，可自定义。试卷内容仍由原文件渲染，未重写题干或答案；缺少音频、仅有解析及不可独立分套的原文件仍如实标注。
- 旧 `#notebook`、`#exams` 地址兼容进入新界面；现有进度、答卷与草稿不清空。

## 鼓励语音

同行之人原“翻开专属手札”入口改为“角色专属鼓励语音”。四位角色各有开始修习、遇到难题、考试之前 3 句，共 12 句。

文本维护于 `tools/build_encouragement.py`，同步写入 `characters/profiles.json` 与课程目录；`voice/dialogue.py` 将其加入正式音频索引。播放严格校验角色与全文 SHA-256，不借用其他角色录音。均为角色参考音色 AI 原创配音，非官方录音。

原有恋爱/好友选择独立保留为“关系选择”，仍需原阈值与完成章节条件；鼓励语音不会增加好感。
