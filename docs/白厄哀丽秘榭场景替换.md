# 白厄邀约 · 哀丽秘榭场景

用户提供的场景位于项目根目录 `哀丽秘榭的麦田_by_小二今天吃啥啊_a75da35763d9f35621c965f43c74fa09`，作者为小二今天吃啥啊。原文件保留不修改。使用白天枝叶风摆工程内的黄昏光照，沿用打包贴图、风车、远山、麦田及树木骨架。

替换范围为白厄74秒邀约主片、连续字幕版、两组选项的四段回应，以及文字邀约全部节点共用的三维麦田。其他角色和自习室不受影响。角色及镜头曲线通过新旧工程摘要比对，动作、表情、落座支撑、对白时长与播放速度保持原样。

制作工程和媒体在 `blender/build/phainon-elysia`。`delivery-status.json` 区分 rendering、encoding、published、failed；只有所有视频完整解码通过才原子更新两份电影规格文件中的输出目录与 media_revision=4。渲染期间继续提供原动画。

人物和桌椅周围清出3.2×4米的椭圆空间，并补齐土壤地面。移除旧场景麦田、村屋、云片及太阳圆盘，防止叠景。保留原麦穗分布与风场，对重复麦穗原型制作轮廓LOD，关闭环境大范围阴影，保留人物补光。此版本不启用原场景体积雾与体积光束。

文字邀约使用同一场景导出的 Draco 压缩GLB；中央地面、远景麦穗颜色与天空另作网页适配。天空由原Blender世界着色器烘焙，不直接把蓝天天空图作为黄昏天空。浏览器解码器随项目本地提供，不依赖外部CDN。CSP仅为本地解码增加 blob Worker 与 WebAssembly 编译权限。

复现顺序：

1. `blender/replace_phainon_environment.py`：从已有第三版动作工程生成新场景副本及审看帧；生成器也已接入相同替换函数。
2. `blender/bake_elysia_sky.py`、`blender/export_elysia_outing.py`：烘焙天空、导出网页场景。
3. `blender/verify_elysia_motion_preservation.py`：从保存工程比较角色、表情和镜头曲线。
4. `tools/render_phainon_elysia.py`：流式渲染主片与四段回应。每个视频使用独立临时帧，避免并行写入冲突。
5. `tools/publish_phainon_elysia.py --wait`：等待全部渲染，核对时长/帧数/分辨率与原配音摘要，完整解码、生成连续版及海报，通过后切换网页动画资源。
6. `web/tests/elysia-outing-browser.mjs`：实际网页加载场景截图与脚本错误检查。

网页场景为 `blender/build/outings/wheat.glb` 和 `wheat.json`，缓存版本为4。原麦田的 `.fbx`、UE原生地图不属于当前网页邀约使用的资源。
