# 四人步态优化

参考：[雲顶动漫动效中心《走路动画の浓缩教程》](https://www.bilibili.com/video/BV1Bp5K6QEEj/)。本次查看了髋部左右运动、腿部关键姿势、躯干旋转和完整展示画面；并非导入作者的动作文件。

## 已实现的动作逻辑

- 支撑脚使用世界坐标落点，摆动脚使用平滑抬脚弧线和小幅脚踝转动。
- 每步先吸收重心再回升；骨盆横移、骨盆与胸腔反向旋转、对侧摆臂一起驱动。
- 起步和收步使用缓动包络，转身仍以两脚轮流换位完成。
- 四人使用同一骨架解算方法，各自保留原骨架；风堇、遐蝶的摆动更克制，白厄幅度更大。
- 24 秒片段中，6–9 秒、18–21 秒为行走，其他时段为站立与转向。老师课堂版本另保留授课手势。

## 文件与入口

生成器：`blender/create_classroom_motion.py`。
四人动作副本：`blender/walking/`，分别包含 BLEND、FBX、GLB。
课堂老师：`blender/animated/anaxa.*`；更新前副本：`blender/animation-backups/walk-v3/`。
两位同学的已修形坐姿不被行走导出覆盖；课堂不强制他们离座。

对照页：`/static/walk-preview.html`。支持四人同屏、暂停、拖动时间和自由观察。
这不是新增课堂寻路系统；学生和助教的行走片段可用于后续进出教室和状态切换。

UE 导入器：`ue5/install_walk_v3.py`。四人动作位于 `/Game/TreeCourt/WalkingV3`；只在 `L_StoryClassroom` 替换老师播放的动画，不写原地图 `L_Classroom`。

## 复现与验收

1. Blender 后台执行 `blender/create_classroom_motion.py -- --walk-library`。
2. Blender 后台执行 `blender/create_classroom_motion.py -- anaxa`。
3. Blender 后台执行 `blender/audit_walk.py`。
4. 运行 `npm.cmd --prefix web/renderer run build`。
5. UE Python commandlet 执行 `ue5/install_walk_v3.py`。

`blender/walking/reports/quality.json` 记录每人 577 帧的实际烘焙骨骼支撑脚位移和循环接缝。
这是脚部与接缝检测，不能替代衣摆/头发的连续碰撞检测，也不能证明动作已与参考逐帧一致。
生成与导入是否完成，以报告和运行日志为准，不以本说明的存在判断。

## 2026-10-24 关键帧重做（脊柱骨 + 中间帧）

参考：MiaoBox《人物动作，K帧经验，脊柱骨和中间帧》（BV1Qsz4BtE1U）。

- 走路相位改为**关键帧曲线**（`WALK_KEYS`：接触/下沉/经过/抬起；相位 0=左脚接触、0.5=右脚接触），中间帧用 smoothstep 过渡，替代原来的纯正弦驱动。
- **脊柱链**：骨盆先动（`下半身` 绕 Y），`上半身1` 反向 −0.75×，`上半身2` 胸腔滞后，`首/頭` 做稳定；不再靠根节点摇晃制造动感。
- **中心**：接触后下沉、经过支撑腿时抬起（一个步幅两次起伏），并带横向重心偏移；脚仍用世界坐标落点 IK，不靠身体上下飘。
- 重新烘焙四人：`blender/create_classroom_motion.py -- --walk-library`。
- 审计：`blender/audit_walk.py` 全通过（支撑踝最大帧间位移 0.118–0.146 mm，循环接缝 ~2.4e-7）。
- 运动量化：`blender/analyze_walk.py` → 骨盆 ↔ `上半身1` 有符号相关 **−0.991**，中心起伏 2.24 cm、横向 3.49 cm，数据在 `blender/walking/reports/walk-motion.json`。
