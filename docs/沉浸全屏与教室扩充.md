## 复现

1. Blender 执行 `blender/build_story_classroom.py -- --output=<classroom-fuller 的绝对路径>`，直接生成最终椅架结构。`adjust_chair_clearance.py` 是本次已生成环境的增量修正记录，首次全量重建无需重复运行。
2. 执行 `tools/verify_classroom_layout.py`，再由 Blender 执行 `blender/audit_furniture.py -- --paired --room=<classroom-fuller 的绝对路径>`。
3. 执行 `tools/publish_fuller_classroom.py`，UE Python 执行 `ue5/publish_fuller_environment.py`。
4. 在 `web/renderer` 执行 `npm run build`，刷新网站；已经打开的 UE 场景需重新加载。
