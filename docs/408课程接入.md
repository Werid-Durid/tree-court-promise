## 章节清单

### 计算机网络 · 56 点
- 网络体系结构与性能（7 点）：网络组成、分类与分组交换；速率、带宽与吞吐量；发送、传播、处理与排队时延；时延带宽积与往返时间；协议、接口与服务；OSI、TCP/IP 与封装；连接服务、可靠性与网络边界。
- 物理层、编码与复用（6 点）：数据、信号与通信方式；编码与调制；奈奎斯特与香农公式；传输介质与设备；复用、交换与接入；码分多址与正交码。
- 数据链路层与局域网（12 点）：封装成帧与透明传输；奇偶校验、海明码与 CRC；停等 ARQ 与序号；GBN 与选择重传 SR；滑动窗口与利用率；ALOHA、CSMA 与退避；CSMA/CD 与最短帧；以太网帧、MAC 与冲突域；交换机自学习与转发；VLAN、生成树与交换环；802.11、CSMA/CA 与隐藏站；PPP 与广域链路。
- 网络层、编址与路由（15 点）：网络服务、转发与路由；IPv4 地址与子网掩码；CIDR、VLSM 与路由聚合；最长前缀匹配；ARP 与逐跳 MAC；IPv4 数据报首部与 TTL；IPv4 分片与重组；DHCP 地址配置；ICMP 与网络诊断；NAT、NAPT 与地址边界；距离向量、链路状态与分层路由；RIP、OSPF 与 BGP；IPv6 与地址表达；IP 组播、IGMP 与移动 IP；路由器组成与 SDN。
- 传输层与 TCP（10 点）：端口、多路分解与套接字；UDP 报文与校验；TCP 字节流、序号与确认号；三次握手与序号同步；连接释放与 TIME_WAIT；重传、RTT 与计时器；接收窗口与流量控制；拥塞控制与窗口约束；慢开始、拥塞避免与快速恢复；TCP 吞吐与端到端追踪。
- 应用层与跨层综合（6 点）：客户服务器与 P2P；DNS 层次与解析；FTP 的控制与数据连接；电子邮件与 MIME；HTTP、持久连接与状态；WWW 访问的跨层过程。

### 计算机组成原理 · 52 点
- 计算机系统与性能（5 点）：存储程序与系统层次；硬件组成与指令执行；软件、机器级接口与语言转换；时钟、CPI 与 CPU 时间；性能比较与加速比。
- 数制、编码与数据表示（7 点）：进位计数制与转换；定点原码、反码与补码；符号扩展、零扩展与截断；移码与阶码；IEEE 754 与特殊值；大小端与数据对齐；C 类型转换与数据解释。
- 算术逻辑运算与运算器（8 点）：逻辑运算与门电路；半加器、全加器与进位链；补码加减与溢出；算术移位与逻辑移位；乘法、Booth 与扩展积；除法与商余数；浮点加减与精度损失；ALU、标志位与运算器。
- 存储层次、Cache 与虚拟地址（9 点）：存储层次与局部性；SRAM、DRAM 与 ROM；主存编址、芯片与容量扩展；多模块与交叉编址；Cache 映射与地址分解；Cache 替换与写策略；命中率与平均访存时间；页表、TLB 与虚拟地址；Cache、主存与虚存综合。
- 指令系统与程序的机器级表示（6 点）：指令格式与扩展操作码；寻址方式与有效地址；相对寻址与分支位移；RISC、CISC 与 ISA；C 表达式、数组与控制流；过程调用与栈帧。
- CPU、数据通路与控制器（6 点）：CPU 寄存器与数据通路；取指与指令周期；单总线与多总线数据通路；硬布线控制器；微程序控制器；异常、中断与返回。
- 流水线与并行体系结构（5 点）：流水线时空图与吞吐量；结构、数据与控制冒险；数据转发与 load-use；多发射、超标量与超流水；多处理器、SIMD 与硬件多线程。
- 总线与输入输出系统（6 点）：总线组成与带宽；总线仲裁与定时；I/O 接口与地址编排；程序查询与中断 I/O；中断优先级与屏蔽；DMA 与总线占用。
