# 四人动画与自习室

网站的「同行之人」为四位角色分别提供动画邀约。白厄麦田版继续保留；新增三部为架空原创相处，不复刻官方或同人视频对白：

| 角色 | 动画 | 场景 |
| --- | --- | --- |
| 那刻夏 | 雨停之前，不必归还 | 雨窗、书架与阅览回廊 |
| 风堇 | 替你留一朵晴天 | 花庭、茶杯与花架 |
| 遐蝶 | 在晚风落下以前 | 暮色露台、蝶影与远水 |
| 白厄 | 把今天留在风里 | 麦田与晚风 |

三部新增主片各 60 秒，包含两处暂停选择，每处两个独立回应。对白、字幕与配音均对应角色；选项回应播放完才提交选择并继续主片。播放进度分别保存。字幕连续版也可单独打开。

普通自习室和「专注陪伴模式」均可从那刻夏、风堇、遐蝶、白厄中选一人。所选角色单独坐在对面，共读书页并有呼吸、眨眼、抬眼和发衣次级运动。四人各有独立的 20 秒、720p、24 fps Blender/Eevee 循环；切换陪伴角色不重置计时，选择保存在本机浏览器。切出页面暂停计时与视频。环境声仍由用户主动开启。

角色沿用原 MMD 网格、图集及表情通道。三渲二使用既有卡通分阶材质；发衣采用骨链阻尼与接触代理，并非全网格布料模拟。口型使用声音包络或回应节奏驱动，并非逐音素匹配。

遐蝶的服装补充图集 `衣+.png`、`衣2+.png` 在部分透明区域保留白色 RGB。不透明 PMX 材质通过独立图像副本读取 RGB，避免透明预乘把身体染黑；原贴图文件及其他透明材质保留各自语义。该修复位于 `blender/materials/opaque_atlas.py`，陪学媒体修订号为 3。

陪学手部已修订：按各模型的掌面、指骨与手套网格校准书面接触，前臂分担旋前，避免手腕单独扭转。右手循行、左手重新落稳、视线先行和抬眼采用不同时间窗；遐蝶额外校准各指落点。书页与桌面各保留至少约 3 毫米的接触余量。独立核验读取实际求值后的手部网格，检查每段 480 个画面及第 481 帧循环端点，同时检查手腕相邻帧位移和循环首尾姿态。视频按媒体修订号更新地址，避免浏览器继续使用旧片。

课堂截图中的椅子另行修复：移除错位的阶梯后脚，改为贯穿座面后角的连续后柱；网页和 UE5 教学课堂同步更新。12 把椅子均检查部件连通与后柱落地。原有角色、课堂逻辑与存档保留。

## 文件与复现

- 剧情配置：`data/cinematics/{anaxa-rain,hyacine-tea,castor-dusk}.json`。
- 配音生成：`tools/dub_companion_films.py`，输出至各动画目录的 `audio/`。
- 动画制作：`blender/build_companion_animation.py`，参数 `--character=anaxa --kind=study` 或 `--kind=outing`。
- 流式编码：`blender/companion_video.py`，不保留整套渲染帧。
- 批量制作：`tools/render_companion_batch.py`。
- 媒体核验：`tools/finalize_companion_media.py <角色> <study或outing>`。
- 邀约输出：`blender/build/companion-films/<动画标识>/`。
- 陪学输出：`blender/build/study-companions/<角色>/`。
- 课堂修复核验：`tools/verify_classroom_chairs.py`。
- 浏览器验收：`web/tests/study-companions-browser.mjs`。
- 手掌与接触解算：`blender/study_hand_motion.py`。
- 手部修订制作：`tools/rebuild_study_hands.py`，先输出至 `blender/build/study-revision/`。
- 逐帧网格检查：`blender/verify_study_hand_contacts.py`。
- 核验后替换：`tools/publish_study_hand_revision.py`；核对源场景哈希，最后替换验证元数据。

每个输出目录保留可编辑 `.blend`、最终视频、海报和构建报告。媒体完整解码通过后写入 `verification.json`，API 只有确认资源完整才返回 `ready: true`。
