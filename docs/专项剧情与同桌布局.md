2026-10-21。本轮用户已取消讲义/时间戳作为教学接入前置条件，并明确允许以本地 Blender / UE Python 后台脚本代替当前缺失的 MCP。

## 教学接入

`knowledge/publish_skills.py` 将 15 条技巧发布为阅读、听力、写作三个独立实战小章。总计 10 个可选章节、81 个知识点。
旧章节、知识点 ID、检测答案保留；新增内容使用独立 ID，不重解释已有错题和检测记录。
阅读使用三条完整思路线索；写作使用卡片排序、功能匹配、修改匹配。素材和台词为原创改编，没有声称逐字复现未读取的课程。

`web/frontend/story-engine.js` 负责结构交互，`web/backend/skill_interactions.py` 校验完整响应；未知、重复或缺失卡片不被接受，不能仅提交自报结果。
`characters/profiles.json` 从既有角色档案提升为唯一角色文本来源；没有改变四人关系定位。课程构建和 API 读取该文件。语音参考档案仍单独保留，不作为角色人设来源。
自习室继续仅播放轻量烘焙循环，不新增考核或实时衣发物理。

## 两排同桌

构建目录：`blender/build/classroom-paired/`。两排，每排两张独立课桌，桌面边缘相接。遐蝶与白厄同坐第一排，第二排两张空座。
单桌宽 0.76 m、深 0.56 m；椅面宽 0.54 m、深 0.50 m、坐面高 0.48 m。桌面顶高 0.845 m，配合现有手腕与书本接触；没有直接降到提案中的 0.76 m，以免坐姿手部悬空，最终以模型接触为准。
排距 1.70 m；角色与家具站位共用构建目录中的 motion.json / layout.json。碰撞体包括桌腿、椅腿、靠背，主通道在座位两侧。
新的坐姿修形只写构建副本，同步保留 UV、权重与相对形态键；原始角色与旧坐姿资产不覆盖。
四位角色在 13 个采样时刻无顶点进入被检查桌椅 AABB；这是当前坐姿摆位抽查，不是连续布料或人物互碰的全覆盖证明。
UE 资源：`/Game/TreeCourt/PairedRoom`、`/Game/TreeCourt/PairedSeating`；更新地图仍为 `L_StoryClassroom`。

## 配音覆盖与边界

`voice/dialogue.py` 收集角色开场、章节开场、老师出题与两种反馈、记忆钩子、助教提示、同学回应、听力朗读及关系/学术支线、检测说明。
当前共有 543 个台词入口。相同角色与相同全文共用一条录音；每条记录保留文本和参考音频哈希。
使用现有本地 Qwen3-TTS 角色参考音色 AI 合成，并非官方录音。主观相似度与逐字发音仍需试听，哈希校验不证明音色一致。
Web 已取消系统标准声线回退；无匹配角色录音时明确提示尚未就绪。默认开启自动配音，但尊重已保存的手动关闭设置与浏览器播放权限。
`/api/voice-status` 按当前台词重新计算有效覆盖，不把旧文本录音算作新台词就绪。部分生成不算全量完成。
当前批次与全量收尾由 `tools/finish_voice_job.ps1` 衔接；每条成功即保存，若被用户中断可从检查点续跑。最终结果以 `data/voice/research/final-verification.json` 和 queue-status.json 为准。
