# 自习室动态壁纸 · 设计规格

当前网页使用四人可选的 Blender 三渲二陪学循环，详见[四人动画与自习室](四人动画与自习室.md)。下文记录早期单人动态壁纸方案，UE5 自习场景资产继续保留。

更新：2026-10-22。目标：参考三支 Bilibili 视频，用本机 Blender 建模 + UE5 制作一个「自习室」场景，以循环动态壁纸形式呈现，并内置音乐歌单。

## 2. 设计目标

1. **自习室是独立的亲密空间**，不是把正式教室缩小：暖木 + 羊皮纸 + 黄昏窗光 + 一盏台灯，氛围安静、昏昏欲睡（呼应 ASMR 的 😴💤）。
2. **那刻夏坐在书桌前写字**：桌面摊开天体物理教材、一支笔、几页纸、一杯茶；他低头书写，动作轻柔循环。
3. **循环动态壁纸**：固定机位 + 极慢镜头漂移 + 空气中尘埃微粒 + 台灯暖光呼吸，首尾无缝循环，不打断。
4. **内置歌单**：参考「写作业听音乐」的 lofi / 学习氛围，内置若干首可循环的环境音乐，可切换、可暂停、显示歌名与进度。

## 3. 自习室布局（坐标：x 左右 / z 纵深 / y 高度，单位米）

房间约 **7.5 × 6.0 × 3.4**（比正式教室 15.5×14.8×4.6 更小更亲密）。沿用 `blender/build_story_classroom.py` 的 `xyz(pos)=(x,-z,y)` 约定。

| 天花板 | (0, 3.4, 0) | 7.5×0.12×6.0 | 暖石膏 + 深色木梁 |
| 后墙（书架墙） | z=−3.0 | 满墙 | 通顶书架 + 满架书 |

光源：左窗黄昏主光（暖金，俯角约 35°）+ 台灯点光（暖橙，呼吸）+ 中冷补光。Blender 用 Eevee/合成器近似；Web 用方向光 + 点光；UE 独立配光，不把 Blender energy 直接搬过去。

## 4. 镜头循环（动态壁纸）

- 机位：书桌斜前方，视点约 1.5 m，看向那刻夏上身与桌面（半身构图，呼应 BV1riGbzeEHK 的表演机位）。
- 循环：一个周期约 60 秒，由「极慢右移 → 轻微推近 → 回到起点」三段缓动组成，首尾位置/朝向/景深完全一致，无缝循环。
- 运动来源：台灯呼吸、尘埃微粒飘动、那刻夏书写手部、窗外云影，均为低频周期，不与镜头周期打架。

## 5. 内置歌单

参考「写作业听音乐」的 BGM 歌单（BV17i421r7kv 的 BGM 见评论区）。歌单以 **学习 / lofi / 安静器乐** 为取向：

1. 不止在落日黄昏时爱你（参考视频 1 标注歌曲，仅作条目与说明，不捆绑未授权音频）
2. 黄昏书房（原创程序化环境音：暖 pad + 柔和钢琴动机）
3. 雨声与旧书（程序化：低频雨点 + 纸页声 + 柔 pad）
4. 深夜里的一盏灯（程序化：极慢和弦 + 呼吸底噪）

为避免版权问题，条目 2–4 使用**本地 Web Audio 程序化生成的循环环境音乐**（非采样他人作品）；条目 1 为占位说明。播放器支持顺序播放、单曲循环、上一首/下一首、播放/暂停、进度显示，并可在自习室界面内切换。

## 6. 资产与文件计划

## 7. 边界与说明

- 本会话模型无图像输入，无法目视核对渲染画面；几何与坐标按既有验证过的课堂管线复用，最终画面以**生成的预览图**交由用户确认后再微调。
- 三渲二材质、桌椅人体工学沿用项目已确认参数；不新增实时布料/头发物理。
- 原角色 PMX/贴图、正式课堂 `L_StoryClassroom` 与 `story_classroom.*` 不被覆盖。

## 8. 复现与运行

```powershell
# 1. Blender：自习室几何 + 那刻夏写字动画
& D:/blender/blender.exe --factory-startup -b --python blender/build_study_room.py
& D:/blender/blender.exe --factory-startup -b --python blender/create_study_motion.py

# 2. Web：打包动态壁纸渲染器
npm.cmd --prefix web/renderer run build

# 3. UE5：导入自习室 + 暖光 + 那刻夏动画（生成 L_StudyRoom）
& D:/UE5/UE_5.8/Engine/Binaries/Win64/UnrealEditor-Cmd.exe ue5/TreeCourt/TreeCourt.uproject `
  "-ExecutePythonScript=$PWD/ue5/install_study_room.py" -unattended -nosplash -nullrhi

# 4. 启动网站，访问动态壁纸
#   http://127.0.0.1:8765/         学习应用（「自习室」页有入口）
#   http://127.0.0.1:8765/wallpaper 独立动态壁纸 + 内置歌单
```
