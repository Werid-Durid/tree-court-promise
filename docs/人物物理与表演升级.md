## 1. 真实物理（MMD 刚体 + 关节）

### 发现

源 PMX **自带物理**，此前 `blender/build_characters.py` 的导入参数 `types={"MESH","ARMATURE","MORPHS"}` 把物理丢掉了（报告里也写着「未烘焙 MMD 物理」）。

| 角色 | 刚体 | 关节（导入初值） | 骨骼 |
|---|---|---|---|
| 那刻夏 | 377 | 5980 | 511 |
| 风堇 | 411 | 10772 | 563 |
| 遐蝶 | 376 | 8712 | 565 |
| 白厄 | 297 | 3461 | 495 |

其中那刻夏有 33 个头发刚体（类型 1/2）。

### 管线

```
PMX 导入(types 含 PHYSICS)
→ mmd_tools.build_rig()            # 建 CHILD_OF / COPY_ROTATION 约束
→ 追加动作
→ ptcache.bake_all()               # 跑刚体缓存
→ nla.bake(visual_keying=True, only_selected=False, use_current_action=True)
→ 导出 GLB/FBX（只选角色网格 mmd_type=NONE + 骨架）
```

### 关键坑

- **导出必须排除物理刚体**：`mmd_tools.build_rig()` 会把刚体做成 **377 个 MESH**（材质 `mmd_tools_rigid_*`）。整场景导出后，网页把它们当角色材质套纸片着色器 → `normal` 未定义、GLSL 编译失败。用 `use_selection=True` 只选角色网格 + 骨架即可。
- **材质/拓扑要补生产版处理**：`repair_material` + `isolate_material_surfaces` + `apply_character_style`，否则顶点数（27669）与生产版（32644）不一致。
- 烘焙结果：那刻夏 5110 条 F-Curve / 330 条头发曲线；四人课堂头发曲线 210–570 条。

## 7. UE 表情的收尾步骤（手动）

序列 `/Game/TreeCourt/Sequences/TC_Anaxa_Expression` 已创建、保存并绑定了老师；但 UE5.8 的 Python 未暴露 `MovieSceneMorphTrack`（`getattr(u,'MovieSceneMorphTrack')` 返回 None），所以轨道与关键帧需在编辑器里手动完成：

1. 双击打开 `TC_Anaxa_Expression`；
2. 右键 `TC_anaxa` 绑定 → `Add Track → Morph Target`；
3. 在 Morph 轨道勾选 `悲しい`、`涙`、`口角下げ`；
4. 在第 1 / 30 / 60 帧分别打关键帧（0 → 0.55 → 0）；
5. 保存序列；在地图里放 `Level Sequence Actor` 指向该序列并勾选自动播放。

这样 UE 端就能在打开地图时自动展示难过表情，与网页端的情绪按钮对齐。
