# 408 真题试炼

入口：`http://127.0.0.1:8765/#cs408-trials`；也可以从“智库 → 考试区 → 408真题试炼”或 408 课程板块菜单进入。

## 本轮内容

- 按年份接入 `408真题/papers-rebuild/` 的 2009—2026 年 18 套试卷及 `408真题/answers/` 的 18 份对应参考答案。
- 题目仍展示本地 PDF 原页，图表、算法和代码不通过 OCR 重写。索引保存原文件 SHA-256 与页数；每份试卷已确认包含第 1—47 题且没有混入答案章节。答案中的扫描页直接按图显示，不要求具备文本层。
- 独立答题卡：40 道 A—D 单选，7 道综合应用题，以及草稿。综合题可保存代码、换行和中文推演。
- 默认 180 分钟，可自定义；刷题模式不限时。服务端保存截止时间，刷新不会重新计时，到期后锁定答卷并保留已保存内容。
- 考试进行中仅能访问原卷；参考答案页和文件下载在交卷后开放。刷题模式可随时对照答案。
- 对照原文件自评，不生成未经核验的自动 150 分成绩。原英语试卷、作文/翻译答题卡及已有答卷继续保留。
