# 核心词汇课堂

入口：课程表 → 四级英语 → 核心词汇课堂。原独立词库页也提供“在 3D 课堂中学习”。板块筛选为“核心词汇课堂”后，可选择 Unit 1–10、课时、具体起点，随时进入章节检测。

## 课程内容

用户指定的 2,327 个词按原书顺序、每课最多 16 词编成 150 节。每词稳定关联原词条 ID、完整中文释义和 PDF 页码。老师讲词、助教联想、遮义回忆三个步骤独立保存；切步骤不记作答，进入回忆才显示三个释义锚点。两个同学分别提供精炼释义和互相抽查的学习方法。作答后无论是否匹配都提供记忆钩子，可继续下一词。

这是基于词表自动编排的课堂内容。记忆钩子采用词形、释义与遮挡回忆练习，不编造词根、词源或未经验证的英语例句。原页随时可查。原书 OCR 的校对限制仍适用。

编译脚本：`knowledge/build_vocabulary_classroom.py`。修改词库后，应先重新发布词库，再运行此脚本更新课堂。脚本幂等，只重建自己生成的课堂；不修改原角色档案或既有知识点。以后大幅调整分课方式需要保留已发布课时 ID，避免历史检测无法回放。

## 场景联动

网页继续承载对白、联想选择、学习进度与检测，已有 UE5 游戏窗口展示教室和人物。`/api/stage/events` 通过本机 Remote Control 更新 `L_StoryClassroom` 中既有的 `TC_LessonWord` 和 `TC_LessonLine`。讲解显示词与释义，回忆阶段遮住释义，反馈阶段恢复释义。网页工具栏显示真实 UE5 回执。浏览器自己的 3D 场景同步更新黑板与说话角色镜头；不能把浏览器 WebGL 截图当作原生 UE5 截图。

启动原生场景使用项目根目录 `启动树庭3D课堂.bat`，或既有 `ue5/start-game.ps1`。本轮未改模型、物理、场景资产及 Remote Control 权限。原生 UE5 镜头与对白 UI 仍是既有实现，本轮新增映射仅为黑板文本；中文释义的主要可读界面是网页对白与手札。

## 状态、声音与验证

课堂沿用原来的作答、章节检测、好感度规则。词卡和课堂同一个词共用每日练习贡献额度；旧记录保留。大目录放入 IndexedDB 缓存，避免挤占 localStorage 学习事件空间。

新增台词已进入现有角色配音索引。仅播放全文与角色都一致的已生成音频；新增词汇台词与独立英文发音已接入本机批量生成；生成中的句子显示待生成，不套用旧录音或其他声线。词库页实时显示发音和课堂台词就绪数。根目录 `启动补全词汇配音.bat` 可在中断后续跑。

测试覆盖词表逐词映射、所有词可从章节到达、服务器检测判分、同词每日额度、遮义阶段不泄露释义与反馈恢复。独立测试库验证了角色交接、错误后的记忆钩子、继续下一词及刷新恢复；另读取原生 UE5 黑板的 Text 属性确认同步。
