## 达到同类动画效果的技术与制作顺序

1. **分镜与台词先行。** 每个交谈段落定义说话人、语气、视线对象、起止姿势、手势重音及留白。先确定音频长度，再制作姿势与镜头，避免让一条待机动作承载所有情绪。
2. **保持模型完整。** 保留当前修复后的面片、Alpha、双面配置、独立骨架和 Morph。角色图集决定腮红、唇色与虹膜；卡通皮肤需要受控明暗和面部阴影，不需要写实毛孔。精修阶段可额外制作面部阴影遮罩与描边权重，不能假定原模型自带这些数据。
3. **Blender 表演制作。** 以已完成的原骨架烘焙动画为基础，为句子制作关键姿势，明确肩、肘、手腕弯曲平面，使用脚部 IK 控制接地；再处理转身重心、手指、眼睑、视线与衣物次级运动。不同角色保留各自骨架，不直接强套同一套旋转值。
4. **语音与面部配合。** 当前网页使用实际音频振幅驱动嘴部开合，并有异步眨眼和温和表情。进一步精修应制作音素对应的口型与表情曲线，振幅开合不等于完整音素同步。继续使用本项目现有 AI 二创音频，不从作者作品截取语音。
5. **实时卡通渲染。** 角色独立卡通明暗保持肤色；环境使用柔和颜色与倒角几何。对话时启用轻景深，行走时关闭景深，避免自由观察时画面发虚。UE 环境明确重建材质，因为 Blender 节点不能依赖 FBX 自动转换。
6. **镜头和交互一起设计。** 玩家具有独立位置和第一人称视角。对白使视线平滑转向说话者，并按距离调节焦距；不会把玩家身体传送至外部摄影机。交谈结束可恢复移动。更强的影片表演可以另做 Sequencer 片段，并清楚区分可控制与演出状态。
7. **运行时验证。** 分别检查骨架、脚部接地、首尾循环、桌椅碰撞、语音切换、离开课堂时资源释放、移动端触控和学习存档；渲染检查必须在真正播放的关卡与网页中进行，不能只看导出成功日志。

## 本轮已落地

- Blender 生成完整教室：地板、墙面、护墙板、窗户、黑板框与粉笔槽、讲台、书本、课桌椅、时钟、证书、书架、绿植与灯具。GLB、FBX、`.blend` 以及碰撞布局都在 `blender/classroom/`。
- 网页采用全窗口场景加浮层对白。奶油色纸笺、蓝色人物名签、逐字对白和联想选项沿用现有学习流程。
- 玩家支持 WASD、鼠标观察、Shift 快走、E 与附近角色交谈、Esc 释放操作；移动端有方向按钮和拖动观察。墙体、桌椅等共有 17 个静态碰撞盒；讲台区域有视点高度补偿。
- 四个角色继续播放原有课堂动画。对白切换会关注当前说话者；风堇提示和同学回应可以直接交谈，返回课堂不会写入答题事件。
- 音频口型、错峰眨眼、有限转头与轻景深已接入网页。它们是实时基础表演，不是作者原片动画的复制。
- UE5 新增 `/Game/TreeCourt/L_StoryClassroom`，保留原 `/Game/TreeCourt/L_Classroom`。新地图使用相同 Blender 环境与四人动画，`BP_TreeCourtPlayer` 是独立受控玩家，视点约 165 cm，约束在水平面。原生 UE 当前未复制网页完整的对白 HUD、口型和说话镜头调度；完整学习体验请从网页进入。

## 启动和复现

网站继续用根目录 `启动树庭网站.bat`，访问 `http://127.0.0.1:8765/`，进入课程后点击“自由行走”。右上角四个角色名字可直接发起交谈。移动时点场景以捕获鼠标，Esc 释放鼠标；自动配音默认由用户开启。

`启动树庭3D课堂.bat` 优先打开新关卡，仍需本机 UE5，尚未打包独立 EXE。旧关卡完整保留。

```powershell
& D:/blender/blender.exe --factory-startup -b --python blender/build_story_classroom.py
npm.cmd --prefix web/renderer run build
& D:/UE5/UE_5.8/Engine/Binaries/Win64/UnrealEditor-Cmd.exe ue5/TreeCourt/TreeCourt.uproject "-ExecutePythonScript=$pwd/ue5/install_story_classroom.py" -unattended -nosplash -nullrhi
```

制作环境未提供可调用的 Blender / Unreal MCP 工具，沿用本地 Python 自动化入口。`blender/animation-reports/story-room-build.log`、`story-ue-install.log` 与 `story-ue-install.json` 保存执行结果。最初覆盖原关卡的方案被自动审批拒绝，已改为在独立新地图中构建，原地图文件散列保持一致。

验证：13 项 Python 后端/语音测试、8 项 JavaScript 状态/移动测试通过。浏览器实际查看了四人载入、第一人称画面与风堇对白；UE5 使用运行模式截图核对。尚未覆盖手柄、极低配置设备和长时间性能测试。

新关卡 Remote Control 黑板更新已实测收到 `executed: true`。启动时需要 `-RCWebControlEnable` 与 `WebControl.StartServer`，根目录启动脚本已包含这些参数。
