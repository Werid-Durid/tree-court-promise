# 四级核心词库

四级词汇主入口采用用户指定的《英语四级核心词》内文 PDF：38 页，Unit 1–10，共 2,327 个不重复词条。PDF 原件的字节副本保存在 `data/vocabulary/cet4-core-source.pdf`，完整词库在 `data/vocabulary/cet4-core.json`。其他科目及四级真题不变。

## 使用

课程表 → 四级英语 → 本书词汇库，或直接访问 `http://127.0.0.1:8765/#vocabulary`。

- 单词卡片：显示词头，翻看中文，自评记住或还需复习。
- 速记：仅单词和中文，可筛选 Unit、搜索及下载当前筛选的 TXT。
- 拼写练习：根据中文输入英文，支持书中的英美拼写及括号变体；自评不计作客观正确率。
- 点击词条查看对应 PDF 裁图，也可查看整页；真实跨栏、跨页续行分别显示。

复习事件单独保存，沿用既有每日练习贡献上限；不会伪造旧课程完成。旧词汇剧情归档，保留原知识点及事件 ID，保证历史学习记录可重放。

## 提取与校对

原件为图片型双栏词表，使用本地 RapidOCR，结合蓝色词头坐标定位；Windows OCR 和目录中同名 Word 仅作辅助交叉核对，PDF 为来源依据。78 个低置信度词条已逐条对照原图修正，全部 13 处候选续行已人工核对。原 PDF 中三处不属于前词的栏首残行没有并入释义。整本尚未逐词人工审定，页面明确标注识别限制并保留原图入口。

重建时先运行 `knowledge/compile_cet4_core.py`，再运行 `knowledge/publish_cet4_vocabulary.py`。编译依赖 `knowledge/build/cet4-core-vocabulary/` 中的页图、RapidOCR 缓存、稳定词头锚点及 `review-order.json`；不要覆盖校对索引。原始提取脚本仅用于追溯，不要直接覆盖校对后的词库。

## 验证与保留

新功能有 Python 和 JavaScript 判题、来源图、词库完整性及历史兼容测试。独立测试数据库用于浏览器复习验证，未向正式档案写入测试答案。正式 SQLite 的备份和旧事件重放报告位于 `knowledge/build/cet4-core-vocabulary/before/` 与 `validation.json`。

运行时需要 `web/requirements.txt` 中的 PyMuPDF，OCR 只在提取阶段使用，正常背词无需运行 OCR。
