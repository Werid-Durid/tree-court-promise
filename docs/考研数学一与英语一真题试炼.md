# 近十年考研数学一与英语一真题

按2026-10-29已举行的考研年度，近十年取2017—2026。数学一、英语一各10套，共20套，独立于原四六级和408索引。

入口：`http://127.0.0.1:8765/#math1-trials` 与 `http://127.0.0.1:8765/#english1-trials`。智库考试区可按科目／年份选择；高数、线代、概率课程菜单跳转数学一，考研英语课程菜单跳转英语一。两类默认180分钟，可自定义，支持刷题、服务器计时、自动保存、刷新续考、交卷锁定和原文件自评。

## 答题卡

- 数学一2017—2020：第1—8题选择、9—14题填空、15—23题解答／证明。
- 数学一2021—2026：第1—10题选择、11—16题填空、17—22题解答／证明。
- 英语一：第1—40题选择、41—45题新题型、46—50题逐句翻译、51题小作文、52题大作文。新题型提供A—G，具体选项按原卷。
- 数学一满分150、英语一满分100，均不生成未经核验的主观题自动分数。英语一不含听力。

后台按本卷允许题号和选择范围校验，拒绝跨卷制式字段。计时考试答案页与下载受服务端权限限制，交卷后开放；原图与PDF均支持同样的身份、时限和答卷版本保护。
