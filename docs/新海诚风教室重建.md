# 新海诚风课程教室重建

更新：2026-10-22。参考：B站 BV1ku411Z7oe《【中文字幕】Blender 新海诚卡通风格教室场景建模渲染教学》（19 集：参考/椅子/桌子/教室结构 3 集/道具 2 集/窗户 2 集/贴图 3 集/公告板/书本/渲染合成/追加书本/窗帘）。

## 1. 做法与边界

- 场景大意不变：黑板、讲台、12 套课桌椅、左墙三扇窗、右墙书柜/公告栏、后墙两侧柜、吊灯、绿植。
- 在同一坐标体系内重建：**座位/角色位置与旧教室一致**（12 人座，castor/phainon 在第一排中间，anaxa/hyacine 在讲台侧），旧课堂动画无需重做。
- 教程中的「贴图/渲染合成」环节以**调色板分色 + 暖光 + 线脚几何**近似，未逐集复刻其贴图节点与合成参数。

## 2. 重建内容（863 个构件 → 按材质合并）

- 建筑：逐条木地板 + 色差 + 接缝；护墙板（sage）+ 竖向分格 + 腰线 + 顶线脚（crown molding）；端墙同构；吊顶 + 木梁 + 梁托。
- 窗：贴内墙的暖色天空面 + 深色窗套/窗棂/横档 + 窗台 + 两侧多褶窗帘 + 云影。
- 黑板：木框 + 绿板 + 粉笔槽 + 粉笔/板擦 + 两侧壁柱；后墙两侧矮柜与书。
- 讲台：双层台面 + 台阶 + 带嵌板的讲桌 + 教师用书。
- 课桌椅：桌面/裙板/桌腿/横撑/抽屉/拉手；椅面/靠背立柱/三道靠背板/横撑；桌面笔记本、页码线、铅笔、部分座位书本、名牌。
- 道具：右墙三组书柜（每层 12 本、高度与颜色变化）、公告栏（6 张钉纸 + 手写线）、挂钟、四幅挂画、五处绿植、三盏吊灯。
- 材质：23 色暖色新海诚调色板（含自发光 `sky_warm/lamp/dust`）。

## 3. 布局与碰撞

- `layout.json` v4：12 seats、**231 碰撞盒**、`player_start=[1.8,1.65,2.4]`、`bounds=[-7.45,7.45,-6.2,6.4]`。
- 座位坐标与旧教室一致（desk z=0/1.7，chair z=0.62/2.32）。
