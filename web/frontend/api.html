LOCAL API · VERSION 0.1

树庭学习 API

无需联网加载文档资源。完整结构见 OpenAPI JSON ↗。

用户接口需要请求头 Authorization: Bearer <UUID 档案标识>。标识由网站首次启动时创建，保存在浏览器档案中。

GET /api/health 服务与舞台状态

GET /api/catalog 课程、角色与策略配置

GET /api/user 当前档案事件与汇总状态

POST /api/events 批量追加学习事件，事件 ID 去重

GET /api/stats 时长、待巩固词和自习统计

GET /api/recommendations 基线推荐占位

POST /api/materials multipart 文件上传，字段名 file

GET /api/materials 当前档案资料队列

GET /api/materials/{id}/text 当前档案提取文本

POST /api/stage/events 舞台占位回执，executed 始终为 false

追加学习事件示例

{
  "events": [{
    "event_id": "a766d4a6-31f2-4c46-aaf5-4bc3dba2dc07",
    "at": "2026-10-19T10:00:00+08:00",
    "type": "attempt",
    "payload": {
      "point_id": "cet4-01-01",
      "clue_id": "clue-0",
      "response_ms": 6000,
      "study_ms": 6000
    }
  }]
}

后台重新计算好感和完成度，不接受直接提交分数。返回 accepted、rejected、events 和 state。拒绝事件不影响同批其他有效事件。
