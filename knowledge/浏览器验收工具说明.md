# 本地浏览器验收

工具：微软官方开源 [Playwright](https://github.com/microsoft/playwright)，当前已安装版本 1.62.1。使用现有 Edge 的独立无头进程，不连接用户正在使用的 Edge，不读取个人标签页、历史或登录档案。此次无需下载不明浏览器插件。

## 已配置脚本

- `web/tests/calculus-browser.mjs`：在 8779 独立服务完成课程答题、图示、模型动画、桌面/手机与全屏验收。拒绝使用正式端口 8765 运行作答测试。UE 场景事件被本地测试响应拦截，不向编辑器发送测试操作。
- `web/tests/calculus-production.mjs`：只读复核正式服务 8765，禁止所有非 GET API 请求，验证网址、课程数量、样式版本和实际语音覆盖率。

脚本优先使用 `TREECOURT_NODE_MODULES` 指定的依赖目录，否则使用本机已安装的 Codex 运行时 Playwright。工具本身与网站发行包分离。

## 复现

在项目目录中，将 `TREECOURT_RUNTIME` 设置为 `web/.runtime/calculus-acceptance` 的绝对路径，启动：

```powershell
web/.venv/Scripts/python.exe -m uvicorn web.backend.app:app --host 127.0.0.1 --port 8779
```

然后在另一个终端运行：

```powershell
node web/tests/calculus-browser.mjs
node web/tests/calculus-production.mjs
```

测试只创建独立浏览器档案；作答记录写入独立验收数据库。结果输出到 `web/.runtime/calculus-browser/`，本次交付快照保存在 `knowledge/build/calculus/acceptance/`。课程功能、网页 3D 和 UE5 原生场景、配音全量完成分别记录，不混为一个已通过状态。
